CBM FOOD - BAN DA SUA CAU HINH BUILD SHIPPER

Da lam:
- Giu lai source code va cac bai test tu file ZIP ban gui.
- Bo thu muc .git, node_modules va dist cu de tranh mang theo trang thai merge cu / phu thuoc cu.
- Them shipper.html vao cau hinh build Vite de Vercel tao trang shipper rieng.

Cach chay tren Windows:
1. Giai nen thu muc nay.
2. Mo thu muc CBM_FOOD_ban_moi trong VS Code.
3. Mo Terminal > New Terminal.
4. Chay: npm install
5. Chay: npm test
6. Chay: npm run build
7. Neu ca test va build deu thanh cong, thu muc dist se duoc tao. Kiem tra dist co index.html, admin.html va shipper.html.

Luu y:
- Ban nay KHONG mang theo .git, nen khong tu dong ghi de branch hai hoac GitHub hien tai.
- Hay giu lai thu muc cu lam ban du phong.
- Chua push len GitHub/Vercel cho den khi test va build thanh cong.
